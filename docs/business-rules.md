# Business Rules

1. Every user has an email, a role (teacher, student, admin).
2. Every student also has a LondonMetID
3. Every student is enrolled at a Level called L1...LN.
4. Each Level is divided into multiple classes C1...CN.
5. Each Level is taught a set of subjects.
6. Each subject has Lecture, Tutorial and Workshop.
7. A teacher teaches one or more subjects either as Lecture, Tutorial or Workshop.
8. A student takes all the subjects assigned to a Level.
9. A subject has one or more assignments.
10. Only a teacher who teaches a subject can assign assignments for the subject.
11. Each students who takes a subject is allowed to submit assignments for that subject.
12. An assignment has one or more questions.
13. A question has one or more reductions.
14. A teacher who teaches a class can grade a submission by assigning reductions to submissions.
